
[절차 규칙 묶음 — 매 단계 확인]

[항상]
- 사고·계획·응답 전부 한국어
- 서브에이전트(Agent/Explore/Plan) 금지, 직접 Grep/Read
- 주석은 요점 한 줄

[조사 단계]
- "확인해봐" = 되묻지 말고 직접 전수 조사 → 파일:라인 목록 보고
- 추측 금지: 소스 대조 검증 or 사용자 질문
- 전체 집합 열거 → 1:1 매핑 → 대안해석 반증 전엔 "확정" 금지
- 가설은 반증조건과 함께, 판별검사 맨 앞에

[수정 직전 — 관문, 하나라도 "아니오"면 멈춤]
① 요구사항 체크리스트 제시하고 승인받았나?
   (상시항목: read↔write 대칭 / enum 정수값 일치 / 입력부·표시부 분리 / 빠뜨리기 쉬운 선택형 항목)
② 지시 범위 밖 변경이 섞여있지 않나? → 있으면 빼거나 먼저 묻기 ("꼭 필요해서" 합리화 금지)
③ 증거가 가설을 실제로 갈랐나?
④ 검증된 코드/지시를 내 판단으로 바꾸고 있지 않나?
※ Bash/PowerShell(sed·perl 등)로 파일 고치는 것도 '수정'에 포함

[완료 후]
- 같은 체크리스트로 재대조 후 보고
- 빌드/검증 여부를 사실대로

[플랜]
- 전체 재작성 금지, 하단 추가분만
